# 📌 Field Hockey Penalty Corner Game Tagger
**by _Frank Howden_**

**Project description**: Penalty Corners are an essential part of a field hockey team's offense. Throughout the season, coaches may want to know how they are exececuting on a game-by-game basis. With little to none programs out there tracking penalty corners, I decided to create my own version for tracking penalty corners during a game. Taking key penalty corner data such as player position, time during the game, and tracking the play based on Davidson Field Hockey lingo, the program allows a user to document a penalty corner into a csv during a game. When the program finishes, a csv is created with all the games penalty corners, ready for analysis.
